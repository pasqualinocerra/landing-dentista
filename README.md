# 🦷 Landing Page — Studio Dentistico

> **Una presenza digitale moderna, elegante e orientata alla conversione per uno studio dentistico.**

Una landing page progettata per comunicare **professionalità, affidabilità e attenzione al paziente**, trasformando la presenza online dello studio in uno strumento concreto per generare contatti e richieste di appuntamento.

---

## ✨ Il progetto

L'obiettivo era realizzare una landing page moderna per uno studio dentistico, con un'interfaccia pulita e professionale e un'esperienza utente semplice e immediata.

Ogni sezione è stata progettata per accompagnare il visitatore attraverso un percorso chiaro:

**Scoperta → Fiducia → Servizi → Contatto → Prenotazione**

La pagina è completamente responsive e pensata per offrire un'esperienza efficace sia da desktop che da smartphone.

---

## 🎯 Obiettivi

* Presentare lo studio in modo professionale
* Comunicare fiducia e autorevolezza
* Valorizzare i principali servizi odontoiatrici
* Rendere immediato il contatto con lo studio
* Ottimizzare l'esperienza da dispositivi mobili
* Creare una struttura facilmente personalizzabile per studi reali

---

## 🧩 Struttura

La landing page comprende:

* **Hero Section** — prima impressione e call-to-action
* **Presentazione dello studio** — identità e valori
* **Servizi** — panoramica delle principali prestazioni
* **Perché scegliere lo studio** — elementi distintivi
* **Call To Action** — invito alla prenotazione
* **Form di contatto** — raccolta delle richieste
* **Footer** — informazioni e collegamenti

Il design segue alcuni principi fondamentali:

* Gerarchia visiva chiara
* Navigazione semplice

* Spaziature equilibrate
* Tipografia leggibile

## 🚀 Installazione

Clona la repository:

```bash
git clone https://github.com/pasqualinocerra/landing-dentista.git
```

Entra nella cartella:

```bash
cd landing-dentista
```

Installa le dipendenze:

```bash
npm install
```

Avvia il progetto in sviluppo:

```bash
npm run dev
```

Apri quindi l'indirizzo locale indicato da Vite nel terminale.

---

## 🔨 Build di produzione

Per creare la versione ottimizzata per la produzione:

```bash
npm run build
```

Per visualizzare localmente la build:

```bash
npm run preview
```
